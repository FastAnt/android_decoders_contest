# Перенести Git-репозиторий на флешку

Рекомендуемый вариант — один файл Git bundle. Он содержит закоммиченные
файлы и историю, хранит символические ссылки как Git-объекты и подходит
для переноса через FAT/exFAT без копирования рабочих каталогов и сборок.

## Записать на флешку

Из корня `neural_codecs/`, заменив путь реальной точкой монтирования:

```bash
git status --short
git bundle create "/путь/к/флешке/neural_codecs.bundle" --all
git bundle verify "/путь/к/флешке/neural_codecs.bundle"
sync
```

`--all` включает локальные Git-ссылки и достижимую из них историю.
Незакоммиченные изменения, ignored-файлы и персональная конфигурация Git
в bundle не входят. Перед созданием проверьте, что нужные изменения
закоммичены. После завершения записи безопасно извлеките флешку средствами ОС.

## Восстановить на другом компьютере

Создайте рабочую копию в каталоге на диске компьютера:

```bash
git clone "/путь/к/флешке/neural_codecs.bundle" neural_codecs
cd neural_codecs
git log -1 --oneline
```

Дальнейшая работа не требует подключённой флешки. `origin` после такого
клонирования указывает на bundle; когда появится постоянный удалённый
репозиторий, его адрес можно задать отдельно.

Для работы с кодеком выполните [setup](setup.md), при необходимости
[экспорт моделей](model-export.md), затем [round-trip](roundtrip.md).
Медиа, веса, виртуальные окружения, внешние исходники и результаты сборок
в Git не хранятся. Подготовленные модели воспроизводятся экспортёром;
для сверки сохранены [отчёты](model-reports/decoder_core_export_f25.json)
и `runtime-assets.sha256`. f25 FP32/FP16 были повторно экспортированы
с теми же SHA256, что исходные файлы.

Собственные исходные треки, изображения и видео в `media/` из Git
не восстанавливаются: если они нужны на другом компьютере, перенесите
их отдельно. Инструкция получения весов не является резервной копией
пользовательских медиа.
